Choisir le behavior

Behavior Table Torc, 21 behaviors

Donner la liste de scénarios

Une ligne par scénario : famille puis scénario, séparés par une tabulation (copier deux colonnes depuis Excel) ou par « ; ». Un fichier Excel est lu colonne A famille, colonne B scénario, comme le catalogue de Matthieu.

3

Vérifier les liens behavior ↔ scénarios

L’outil reconnaît chaque ligne, choisit un modèle du catalogue et propose le lien. Cochez ou décochez pour corriger.
4

Générer tous les scénarios concrets

Les valeurs viennent du modèle ; 13 règles excluent les combinaisons absurdes.
5

Sauvegarder et relire

Un fichier JSON garde le behavior, la liste, les liens et les concrets avec leur origine.
